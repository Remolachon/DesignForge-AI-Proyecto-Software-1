❓ PREGUNTAS:
════════════════════════════════════════════════════════════════════════════════

P: ¿El cambio de Backend requiere reiniciar algo?
R: No. Next.js recarga automáticamente. Solo actualiza el navegador.

P: ¿Puedo tener ambos backends corriendo simultáneamente?
R: Sí, pero el frontend solo se conecta a uno. Puedes cambiar en segundos.

P: ¿Dañaste algo del código?
R: No. Solo:
   - Cambié frontend/.env.local (URL de http -> localhost)
   - Agregué documentación (.md y scripts)
   - Mejoré manejo de errores en frontend

P: ¿Los datos de un backend se sincronizan con el otro?
R: Sí, ambos usan la misma BD Supabase.

P: ¿Qué pasa si el Backend Local no está corriendo?
R: El frontend dará error. Simplemente ejecuta python -m app.main
